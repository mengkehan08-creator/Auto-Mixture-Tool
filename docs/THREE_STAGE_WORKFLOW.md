# 配比、训练、评测独立作业

新实验默认提交三个独立 ModelArts 作业。后端只配置请求和查询作业状态，不直接下载 OBS 数据。

1. 配比：挂载输入 Parquet，校验后生成全部策略采样集及 dataset_stats.json。
2. 训练：前序作业成功后提交，挂载采样集；多节点依次训练各策略模型。
3. 评测：训练作业成功后提交，将该实验实际模型输出 OBS 地址挂载到每个评测节点。

训练与评测分别配置节点数。评测默认 1 节点、8 卡，评测批量 16，每项最大样本数 -1（全部）。
批量变大会提高显存需求；最大样本数为正整数时仅用于抽样评测，不能和全量结果混用。
关闭评测时只创建配比和训练两个作业。历史两作业记录仍按原来的编排恢复，不追加新作业。

## 模型交接

训练只在首节点生成 models_manifest.json，清单包含每个策略的模型标签、最终检查点步数、
权重及元数据文件路径、文件大小、SHA-256 和采样统计。缺少模型时训练阶段报错，不进入评测。
评测节点挂载训练输出目录后核对清单及文件哈希；校验失败会停止，不使用其他模型代替。
OBS 挂载或权限错误由 ModelArts 返回。不要在训练输出上传完成之前手动启动评测。

模型目录：页面填写的模型输出根目录/runs/本次实验名称/；未填写时使用实验输出目录下
的 runs/本次实验名称/training/checkpoints/。评测自动使用这一实际地址，不需要再次填写。

评测输出包括每个策略的 CSV、comparison_report.json（指标、模型标识、配比采样统计和评测设置）、
comparison_report.md。输出路径取页面的评测输出设置。

## 操作

1. 更新本地工具和 OBS 中的工具代码，二者须为同一版本。
2. 启动 API，打开 /ui；配置配比、训练和评测的各自节点数及参数。
3. 任务配置中检查三个 command，旧复制记录缺少的评测命令会自动补齐。
4. 提交后，在实验作业页查看三个作业的状态和 ModelArts 链接。前序失败不提交后序。
5. 第一轮建议少量数据、较小训练 Token 预算、单节点评测验证，再逐步扩大规模。

评测多节点沿用挂载 NanoChat 的分布式评测实现；本工具解决模型挂载和作业编排，
不能据此承诺评测加速比。需要用实际集群验证模型加载、分布式通信及结果一致性。

## 对应代码

- workflow.py：三个作业的依赖提交、节点配置、OBS 输入输出连接、失败与删除处理。
- stage_runner.py：配比、训练、评测入口选择。
- evaluation_job.py：模型清单发布、完整性检查、独立评测和对比报告。
- run_stem_experiment.sh：独立训练模式在训练完成后返回，不继续运行最终评测。
- EvaluationConfigStep.vue：评测节点、参数及前序模型地址显示。

当前本机测试不能替代 ModelArts NPU 实跑。首次上线前应确认挂载版 NanoChat 使用
model_XXXXXX.pt / meta_XXXXXX.json 检查点格式以及 base_eval 的现有命令参数。
