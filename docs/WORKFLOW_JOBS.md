# 实验作业管理

实验列表按创建时间倒序排列。详情中的刻度表示作业阶段，不代表训练步数或耗时百分比。

在“搜索作业名”中输入完整或部分实验名称即可实时筛选，支持中文及不区分大小写的英文匹配，忽略输入首尾空格。清空搜索恢复全部记录；筛选结果仍按创建时间倒序。打开详情再返回列表保留搜索关键词。

## 删除实验

1. 在列表或详情点击“删除实验”。
2. 确认弹窗中的实验名称；点击“取消”不会发送删除请求。
3. 点击“确认删除并终止作业”后，后台先禁止后续作业自动提交。
4. 等待正在进行的创建请求返回作业 ID，再查询关联作业，对尚未结束的作业请求终止。
5. 确认所有已创建的关联作业结束后，实验从列表移除。终止未确认、鉴权失败或创建结果不明确时，保留记录并显示原因，可在处理后重试删除。

停止接口使用 ModelArts 的 `POST .../training-jobs/{job_id}/actions`，请求体为 `{"action_type":"terminate"}`。沿用当前 IAM、ModelArts 网关和证书配置。内部网关需要允许该停止接口，身份需要具备相应权限。参考：[华为云终止训练作业 API](https://support.huaweicloud.com/api-modelarts/StopTrainingJob.html)。

删除是工具侧的逻辑删除：本地 `result/.workflows/` 保留带 `DELETED` 状态的记录，防止重启或重复请求再次创建任务。不会删除 OBS 数据、采样集、模型、报告，也不会删除 ModelArts 控制台中的历史记录。已消耗的计算资源不能撤销。

接口：`DELETE /api/v1/workflows/{workflow_id}` 返回 HTTP 202 表示受理，不代表远程终止已经完成。通过列表或详情轮询结果；删除成功后详情返回 404。请求删除后即使失败，也不会恢复后续训练自动提交。

当前已用模拟接口验证删除和停止逻辑，真实内部网关终止权限及状态返回需要部署后核验。不明确的创建请求不会按名称猜测或终止其他作业。

对于“待人工核对”或“删除未完成”、没有任何远程作业 ID 且创建结果不明确的记录，删除弹窗要求勾选“已在 ModelArts 核对，确认未创建”。确认后仅移除工具记录，不发送终止请求；后端记录核对时间。仍在提交中的请求不能通过此方式跳过，已有远程 ID 的实验也不能绕过终止检查。对应接口参数为 `?confirmed_not_created=true`。确定尚未提交或已明确创建失败的记录不需要额外勾选。
