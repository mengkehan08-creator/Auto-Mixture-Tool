# 人工与随机策略脚本

在人工配比或随机配比卡片选择“使用自定义采样脚本”，再选择：

- **OBS 地址**：填写已上传的 `.py` 文件地址。
- **上传脚本**：选择文件或拖拽单个 `.py` 文件。每项策略独立选择，可以为多个人工配比方案使用不同文件。

OBS 地址和上传区域在同一卡片中同时显示。两种来源互斥：编辑地址会清除已选文件，成功选择文件会清空地址。直接上传要求 UTF-8，单个文件最多 32 KiB，一次实验合计最多 128 KiB；这些是工具的保守限制，不是 ModelArts 的文件大小配额。更大脚本使用 OBS 地址。

文件选择后暂存在页面内存，提交时内容随压缩分段配置发送到后端和 ModelArts；不需要额外 OBS 上传权限。后端只进行语法与接口声明检查，不执行脚本。在配比容器启动后，内容写入临时目录并由已有采样接口执行，配比进程退出时清理临时文件。训练作业只使用生成的采样集，不再携带上传的源代码。

脚本内容会保存在实验配置中，以支持复制作业，也会进入远程作业配置。因此不要上传包含 Token、secret、密码或其他敏感信息的脚本。本功能仅接收可信内部代码，不是代码沙箱；语法检查不能证明代码安全或采样正确。

## 仓库内样例

- `examples/strategies/manual_quality_first.py`：每个领域内优先选择估算 token 数较大的文本；文件名虽然含 quality，实际并不是按质量分排序。
- `examples/strategies/random_length_aware.py`：按估算 token 数排序后分桶，桶内随机打乱，优先从短文本桶采样。

两个文件均声明 `STRATEGY_API_VERSION = "1"`，实现 `select(pool, context, config)` 并返回候选池中的索引。领域比例与最终数据预算仍由工具控制。依赖需要在训练镜像或离线资源中提前准备，上传脚本不会自动安装包。

开发环境中的位置为 `/home/ma-user/work/Auto-Mixture-Tool/examples/strategies/`。可以先通过 JupyterLab 下载样例至浏览器所在电脑，再通过上传或拖拽选择。

更新开发环境后端与前端，并同步 OBS 中的工具代码；旧版 stage_runner 不会还原上传文件。自定义 command 需继续调用该入口，或自行实现脚本内容还原。复制已提交实验会保留上传脚本；未提交页面刷新不保证保留文件。
