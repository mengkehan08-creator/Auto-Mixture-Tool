## 配比数据与策略

- 输入：规范化 Parquet 目录。示例：`examples/datasets/quadmix_parquet.py`。
- 检查所有分片字段和类型，每片检查前 1000 条记录；额外分批扫描所有分片的 char_count 列，汇总文档数、字符数、文件字节数。按全量字符数 ÷ 4 估算 Token，不读取全部正文分词、不下载数据。中文和代码的实际 Tokenizer 计数可能明显不同。长度列全量检查不等于全文质量审查。云作业启动时重新检查挂载数据。
- 每个策略标题旁可打开说明。人工与随机提供脚本下载，脚本接口仍为 `STRATEGY_API_VERSION = "1"`、`select(pool, context, config)`。
- 样例位置：`examples/strategies/manual_quality_first.py`（实际按长度优先）、`examples/strategies/random_length_aware.py`（按长度分桶随机）。这些是自定义策略示例，不是默认采样算法的同义替代。
- 代理实验步数旁显示每组预计训练消耗：步数 × 8 × 2048 Token，不乘代理实验数，不乘节点数；自定义 command 改批量或序列长度后需重新核算。代理实验数默认 50，建议不少于 50，但不是效果保证。
- 最终采样实际值在创建时仍为“待统计”。数据校验后显示参数范围中点与端点的采样情景估算：输入估算 Token × 采样函数在排名 0～1 的积分。假设 Token 加权排名连续，未计后续过滤、裁剪，重复记录计入；不是最终搜索结果或统计置信区间，不以历史固定数值作标准。

### QuaDMix 搜索范围

每个策略可独立编辑有效参数的下限和上限；相等表示固定参数。默认 ω=[0,0.1]、ε=[0,0.001]、λ=[0,1000]、η=[0,1]。ω/ε/η 限制在 0～1，λ 必须有限且非负，上限不得小于下限。参数实际传到代理候选生成与最终搜索，Top-K 平均仍在范围内。

请求字段为 `sampling_bounds`；YAML 使用 `algorithm_config.sampling_bounds`，例如：

```yaml
sampling_bounds:
  omega: [0, 0.2]
  epsilon: [0, 0.002]
  lambda: [0, 1000]
  eta: [0, 1]
```

ω 决定优先选取的质量排名区域；ε 是所有文档的基础选取率（尾部仅使用此值）；λ 和 η 调节优先区域强度。其他参数固定时提高这些值通常增加总入选次数，但不等于增加唯一文档，也不保证搜索后的训练效果改善。自定义启动命令必须仍调用工具入口并传递参数。

## 统一训练与重复风险

一次新实验共用训练框架、基础模型、Token 预算、每节点设备数及隐藏的训练参数。各作业独立名称、节点数、优先级及 command 保留。单卡批量、验证损失检查间隔和训练期间任务评测间隔仅隐藏，后台默认值仍为 1、-1、-1。

在数据输入阶段和训练配置阶段均显示风险，预算同步。校验输入数据后，根据数据 Token 估算量及当前 ω、ε、λ、η 范围自动计算参数中点情景采样量，无需手动提供实际采样统计。修改参数范围或训练预算时实时更新；更换数据地址后清除数据估算，需重新校验。未完成校验或参数范围无效时不显示虚构倍数。训练预算 ÷ 预计采样量严格超过 3 才红色告警，不阻止提交；恰好 3 倍不告警，参数范围预计无数据时也会警告。这是提交前情景估算，不是最终参数搜索结果；采样内部重复、训练裁剪和批量取整仍影响真实重复次数。代理实验数与步数不作为最终采样量的直接乘数。

“创建实验”确认后恢复全部默认值；“阶段重试”提交前再次确认，继续复用成功的前序输出。

## OBS 评测包

在“评测配置 → OBS 路径 → OBS 评测包”增加名称和目录地址，点击“示例”查看完整约定。可先点“校验数据”；正式提交时再次检查，修改地址后旧结果失效。

完整最小示例：`examples/evaluation/basic/`。上传该文件夹的全部内容，OBS 地址指向包含 `core.yaml` 的目录。

```text
basic/
  core.yaml
  eval_meta_data.csv
  eval_data/science.jsonl
```

支持按约定整理的文本多选题，包括 MMLU、CMMLU、C-Eval、ARC、GPQA 等；选择题记录使用 `query`、`choices`、零起始整数 `gold`。生成题仅支持当前的 `gsm8k`、`math` 答案提取器，记录需有 `query`、`answer`。不是任意原始评测数据直接上传就可执行。

不支持的任务类型、无效答案索引、空数据、路径越界、缺少基线文件等会报错并禁止提交。HumanEval / MBPP 代码执行、多模态、BLEU / ROUGE 等需额外评测器，当前不会伪装成可执行任务。

## 命令联动

各作业显示可编辑的完整命令，不用脚本路径代替命令。默认命令随镜像与 OBS 资源配置刷新，资源上下文以安全引用的环境变量显示。OBS 地址变化通过 ModelArts 挂载生效；容器内固定挂载路径是运行接口，不随 OBS 文件夹名变化。

当前启动命令面向 Python 3.11 / Ascend 镜像，自动定位解释器、离线安装依赖并做启动检查；不能从镜像名称推断并自动适配所有镜像版本。手工编辑的命令不被自动覆盖，点击“恢复此作业默认命令”后重新跟随配置。不要把密钥写入 command。

## 结果与预览

结果分析顶部展示共同有效评测项平均正确率最高的模型，包含并列。新模型清单保存必要策略配置，历史未记录字段不推测。柱形和折线节点表示同一正确率，连线仅辅助比较；最高分为红色，缺失值不按零分处理。
