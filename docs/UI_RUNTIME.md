# Web 控制台部署与运行

本页面由 FastAPI 提供，连接真实的工作流接口，不是双击 HTML 的演示页面。默认一个实验包含两个 ModelArts 作业：配比采样作业，以及依赖其成功完成的训练评测作业。第二个作业顺序训练评测所有所选采样集。

## 1. 管理员准备

在开发环境仓库根目录操作：

```bash
cd /home/ma-user/work/Auto-Mixture-Tool
source .venv/bin/activate
export PYTHONPATH="$PWD:$PWD/src:${PYTHONPATH:-}"
python -c "import fastapi, uvicorn, requests, yaml"
```

如尚未创建环境，先执行 `python3 -m venv .venv`。缺少依赖时按仓库依赖清单安装；无网络环境使用准备好的离线 wheel。控制台依赖和 ModelArts 镜像中的训练依赖是两个环境，不能相互替代。

在页面“确认提交 → ModelArts 作业配置”中填写 API 地址、region、Authorization、workspace_id、镜像地址及镜像仓库 ID、资源规格与资源池。页面提交的值覆盖脚本模板，不需要编辑或运行 `modelarts_training_job.py`。脚本保持占位值即可；直接使用脚本提交的旧方式仍需自行替换占位值。

Authorization 使用密码输入框，仅保存在页面及后端进程内存，不进入作业环境变量、工作流文件或返回结果。后端重启后，页面配置的实验会等待重新授权：填写 Authorization，再点击对应实验的“更新该实验凭据”，恢复原有作业监控，不重新创建已知作业。凭据过期也可用此方式更新；已失败或创建结果不确定的作业不会自动重新提交。

未提交配置会自动保存到当前标签页的 sessionStorage，刷新时恢复策略、节点、批量模式、评测选择和当前步骤。Authorization、API Key 等凭据字段不保存，刷新后需重新填写；数据检查和训练计划也会重新计算。左侧“创建实验”返回当前配置，保留参数和所在步骤，不会弹出清空确认。需要重置时，点击配置页右上角“新建实验”并确认。草稿只在当前标签页会话内保留，不作为跨设备备份；明确新建或实验受理后会移除已保存草稿。浏览器禁止存储或草稿超过 1 MiB 时页面会明确提示未保存，当前配置仍留在内存中。不要把凭据嵌入启动命令或脚本文本。

API 地址必须是可信的 HTTPS 创建作业地址，不要使用带令牌的查询字符串。页面必须通过可信 HTTPS 入口访问；仅在本机调试时使用 localhost。当前没有多用户身份隔离，仅限可信内部用户使用，不能公开部署。

页面中的输入、输出、资源地址和两阶段节点数覆盖对应的作业模板值。使用页面启动时，不需要再次手动运行提交脚本，否则会重复创建任务。

先将工具代码、NanoChat 代码、初始模型与 tokenizer、代理验证集、评测资源和离线依赖上传 OBS；具体目录要求见 `docs/OFFLINE_RESOURCES_AND_OPERATIONS.md`。输入数据应为已经过滤、统一标签的 Parquet 数据，当前页面不提交 Hadoop 转换任务。

## 2. 启动后端和界面

```bash
python -m auto_mixture_tool.cli --workspace "$PWD" \
  serve --host 0.0.0.0 --port 8080
```

另开终端检查：

```bash
curl --noproxy '*' http://127.0.0.1:8080/api/v1/health
curl --noproxy '*' -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8080/ui
```

第二条应返回 200。不要用 `curl -I` 判断页面是否可用，因为页面只接受 GET。

浏览器访问可达开发环境的 `/ui`。如果通过 JupyterLab 使用开发环境，且平台启用了端口代理，可将 JupyterLab 地址末尾的 `/lab` 替换为 `/proxy/8080/ui`，保留此前的实例路径。平台未启用代理时需要管理员提供端口访问入口，内网 IP 不一定能从本机访问。前端接口会保留此代理前缀。

当前服务没有独立用户登录与权限隔离，只能放在可信内部网络或已有认证的 Jupyter 代理后面，不要直接公开到互联网。保持后端进程运行；关闭页面不会停止后端编排，但关闭服务会暂停监控和后续提交。

## 3. 页面填写与启动

1. 填写输入数据 **OBS URI**，如 `obs://bucket/datasets/prepared_parquet/`，不是 OBS 控制台的 HTTPS 网页链接。
2. 填写可自定义的输出根目录，如 `obs://bucket/experiments/team-a/`。作业身份必须有输入读取和输出写入权限。
3. 配置一个 QuaDMix 策略，可增加随机策略和多个人工比例方案。代理实验数、实验步数、搜索次数可编辑。自定义采样脚本填写可信 `.py` 文件的 OBS URI，脚本必须符合仓库采样接口，不是任意训练脚本。
4. 分别选择配比、训练作业节点数。配置 NanoChat 代码、模型资源和初始模型标签。目前实际训练接口为 NanoChat，不支持任意框架上传后直接执行。
   训练参数中可设置 `num_iterations`（0 为按数据预算自动计算，正整数为每个模型的训练步数）、`device_batch_size`（默认 1）、`eval_every` 与 `core_metric_every`（-1 关闭训练中验证/评测，正整数为间隔步数）。固定步数覆盖自动步数，不修改采样集大小；不同策略使用同一设置。增大单卡批量可能导致显存不足或全局批量不兼容，需在目标镜像验证。训练完成后的评测仍由评测配置单独控制。复制实验会保留这些参数。
5. 选择评测资源和任务。`stem` 会展开为六项 STEM 任务。复制旧实验时，`all/core` 预设以及额外单项会显示为可取消选项；选择 STEM 单项或全选时替换互斥预设，避免混选。切回内置资源时保留 OBS 包的编辑内容，但不会将隐藏包计入清单或提交；再次切回 OBS 可继续编辑。自动评估 API 仅保留展示，尚未接入服务。
6. 在确认页查看两个作业、输入输出与节点数，点击“检查配置（不创建作业）”。通过后点击启动。启动会调用真实 ModelArts API，并可能产生计算费用。

配置检查只检查参数和模板完整性，不验证 OBS 对象确实存在、权限足够或镜像依赖齐全。实际任务仍需进行资源与数据检查；建议先小规模验收，再扩大节点数和数据量。

## 4. 输出和进度

离线运行资源以可编辑的 `name + OBS 地址` 列表配置，可增删。默认资源保留内部用途和挂载目录，改名不会改变默认命令所用的路径；新增资源在两个作业中挂载到 `/home/ma-user/modelarts/inputs/custom/<name>`。名称必须唯一且仅包含字母、数字、下划线，以字母开头。删除默认必需资源时必须同时调整两个作业的 command，否则提交检查会拒绝。复制实验会保留列表。

第四步名称为“任务配置”。其中两个 `command` 文本框会从后端加载当前配比、训练评测作业的默认命令，允许编辑；实际提交使用编辑后的命令。留空会被拒绝。复制实验保留自定义命令，旧记录没有命令时加载当前默认值。此功能仅供可信内部用户，命令会被保存到实验配置，请勿嵌入认证凭据。自行修改命令需要保持阶段输入输出和启动环境约定；系统不会自动纠正任意脚本逻辑。

左侧“实验作业”独立管理历史实验。列表显示正在作业、终止（失败）、已完成、等待授权或待人工核对；点击“查看作业详情”查看两个阶段的状态、进度、失败原因、输出地址和 ModelArts 链接。“终止”是状态展示，不是主动停止云端作业的按钮。

点击“复制并调整参数”会将原实验的配置填入创建页面，包括策略、人工比例、脚本地址、节点数、资源和输入输出根目录。复制不创建云作业，也不复制认证凭据或原提交标识；修改后重新填写凭据并确认提交。输出根目录可以不变，新实验会创建独立子目录，不覆盖原实验。历史记录仍只面向可信内部用户，没有多用户权限隔离。

每次实验在所选根目录下创建独立目录：

```text
obs://bucket/experiments/team-a/runs/<实验名称-时间-唯一编号>/
  mixing/    配比阶段输出
  sampled/   各策略采样数据与人工方案清单
  training/  模型、日志和训练评测结果
```

以确认页面显示的实际地址为准。第一个作业成功后，后端将采样集地址作为第二个作业的输入；第一个作业失败则不提交第二个。提交请求受理时不显示进度条，收到 ModelArts 作业编号后才自动进入运行详情页。进度条表示工作流阶段，不代表实时训练 step 百分比。出现失败或状态查询错误时隐藏进度条，保留错误信息、输入配置和输出位置；返回配置不清空表单。

运行详情页为每个已创建作业显示“打开 ModelArts 作业详情”。优先使用平台返回的网页链接；没有返回时，按华为云控制台格式用当前区域和真实作业编号生成链接。页面中的“工作空间名称”仅用于链接的 `workspaceName` 参数，不替代创建作业所需的工作空间编号；默认是当前提供的 `aifm-lmdt-exp_MA_workspace`，切换空间时请修改。第二个作业尚未创建时不生成虚假链接。打开控制台可能需要登录有相应权限的华为云账号。

工作流记录持久化在开发环境仓库的 `result/.workflows/`，不要删除。服务重启后会恢复已知作业 ID 的监控；如果提交响应丢失、无法确认是否创建成功，会标记需要人工核对，避免自动重复创建收费作业。网络查询失败会显示状态并重试。

## 5. 前端维护与验收边界

ModelArts 的单个环境变量值限制为 4096 字符。长配置压缩后以每段最多 4000 个 ASCII 字符传输，容器入口还原并核对摘要；短配置兼容旧的单变量方式。命令和离线挂载列表不重复塞入运行配置。工具另外设有 1 MiB 原始配置安全上限，该值不是 ModelArts 的额度声明。升级时后端与 OBS 工具代码必须同时更新，旧入口无法读取新编码。分段不绕过平台的环境变量总量或请求总大小限制。

最新非敏感参数来自 `configs/modelarts_ui_defaults.json`，与提供的提交脚本核对后填写。页面只补充空字段，不覆盖已编辑的值；Authorization 永不从默认文件返回。默认 command 为完整可编辑的内联命令。复制旧实验时可点击“恢复默认命令”使用新启动流程。详细离线资源与验收边界见 `docs/RUNTIME_HARDENING.md`。

提交后端仅校验 OBS 地址格式并将地址交给 ModelArts，不读取 OBS 数据或检查远程对象是否存在。内置目录输入统一以 `/` 结尾，自定义资源保留用户填写的目录末尾 `/`，策略脚本文件不追加 `/`。ModelArts 返回的对象不存在错误仍需结合实际对象路径与作业访问权限排查。

发布包已包含构建后的界面，开发环境只运行后端即可。修改 Vue 源码时，在有 Node.js 和前端依赖的机器运行：

```bash
cd ui_demo
npm ci
npm run build
```

构建会更新后端 `src/auto_mixture_tool/api/static/index.html`。不要只上传 `ui_demo` 或双击 HTML 来启动系统。

本地自动化测试覆盖接口、工作流衔接、失败阻断、恢复与路径处理；真实 ModelArts、OBS 权限、NPU 通信和多节点训练仍需在目标环境验收。不能将本地测试通过等同于远程训练已成功。
# 模型与评测输出地址

训练配置中的“模型输出 OBS 目录”和评测配置中的“评测与对比报告输出 OBS 目录”可分别编辑，对应 `training.output_obs_uri` 和 `evaluation.output_obs_uri`。只接受有写入权限的 OBS 目录，不接受本地路径或控制台网页链接。留空时沿用实验输出目录。

自定义目录下自动追加 `runs/实验名称/`，各次运行相互隔离。第二个作业通过独立输出映射分别上传检查点与报告；实验作业详情显示最终地址。自定义 command 必须保留 stage_runner 的输出路径约定。部署时同步更新 OBS 工具代码及开发环境后端。
